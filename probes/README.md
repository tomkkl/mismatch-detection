# Agent Audit probes

Probe scripts go here: `probe_agent_audit_v2.py` (round 1), `probe_round2.py` (round 2),
`demo_agent_audit.py` (team demo). Generated cases go in `aa_run/` (git-ignored).

Keep `aa_run/` and everything under it neutrally named. Agent Audit suppresses findings in
test-looking paths (`/tests/`, `/fixtures/`, `/examples/`, `/samples/`, `/mocks/` ...).
